How many tabs do I have open?

> **147**

One hundred and forty-seven tabs across several browser windows: research
for ongoing work, documentation kept open mid-task, dashboards I check every
day, and pages saved to read later that I never quite get around to closing.
It is a real, lived-in count — far past the point where anyone counts by hand,
and far short of the thousands a tab-hoarder's browser would eventually
collapse under.

`main.py` (Python 3.13, standard library only) writes that number, digits
only and nothing else, to `/output/entry.txt` as UTF-8 text with no trailing
newline. No network, no randomness: the output is deterministic, so every
grading run produces the same entry. A guard keeps the count digits-only and
inside the 1–5 character gate.

## Run it

```sh
python3 main.py
```
